# 4. Google Docs

## What is Google Docs?
A browser-based word processor with real-time collaboration, automatic saving and version history. It is free with a Google account and works on any device.

## Key features
| Area | Details |
|---|---|
| Collaboration | Multiple people edit simultaneously, with colored cursors |
| Sharing | Viewer / Commenter / Editor roles; share by email or link |
| Comments & suggestions | Comment threads, `@mentions`, **Suggesting** mode (like track changes) |
| Version history | File → Version history shows who changed what and lets you restore |
| Offline | Enable offline mode in Chrome |
| Export | `.docx`, `.pdf`, `.odt`, `.txt`, `.html`, `.epub` |
| Add-ons | Citation tools, Zotero/Mendeley, Grammarly, diagram tools |

## Formatting for technical documents
- Use **Styles** (Heading 1/2/3, Title, Normal) instead of manual bolding, so structure is consistent.
- Insert an automatic **table of contents** (Insert → Table of contents) based on headings.
- Use **page numbers**, headers and footers.
- Use **Insert → Equation** for math, or Drawings for simple diagrams.
- Use **Tools → Citations** for references (APA/MLA/Chicago).
- Use **Insert → Link** and bookmarks for navigation.

## Good collaboration practice
1. Agree on structure (headings) first.
2. Use Suggesting mode for review.
3. Resolve comment threads when addressed.
4. Name versions (File → Version history → Name current version) at milestones.
5. Set correct sharing permissions before sending links.

## Docs vs LaTeX
| | Google Docs | LaTeX |
|---|---|---|
| Learning curve | Low | Higher |
| Real-time collaboration | Excellent | Via Overleaf/Git |
| Math & typesetting | Basic | Excellent |
| Large structured documents | OK | Excellent |
| Best for | Drafts, team reports, quick edits | Papers, theses, math-heavy work |

## What I learned
- Styles and automatic TOC make documents easier to restructure.
- Version history and comments make group work transparent.
- Choosing the right tool depends on collaboration needs and complexity.
